# Software Setup

## Quickstart

Run in SSH:

```sh
curl https://3ms.3dcoded.xyz/install.sh | bash
```

??? note "Piping to Bash"
    If you'd prefer to not pipe to bash, you can clone the script and run it manually:
    ```sh
    wget https://3ms.3dcoded.xyz/install.sh
    ```
    Review the file contents, then run it:
    ```sh
    bash install.sh
    ```
